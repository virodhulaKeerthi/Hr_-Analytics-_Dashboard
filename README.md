# HR Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an HR Analytics dashboard created using Microsoft Power BI.

The dashboard analyzes employee data to understand workforce distribution,
employee attrition, salary, overtime, job satisfaction, and other HR-related factors.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Dashboard Features

- Total Employees KPI
- Total Attrition KPI
- Attrition Rate
- Average Monthly Income
- Average Job Satisfaction
- Overtime Employees
- Attrition by Department
- Attrition by Job Role
- Attrition by Age Group
- Employee Distribution by Salary Slab
- Employee Attrition Status
- Decomposition Tree
- Key Influencers
- Interactive Slicers

## 📂 Project Files

- `HR_Analytics_Dashboard.pbix` – Power BI dashboard
- `dashboard.png` – Main dashboard screenshot
- `employee_analysis.png` – Employee analysis screenshot

## 🎯 Objective

The objective of this project is to analyze employee data and identify
patterns related to employee attrition, job satisfaction, overtime,
salary levels, departments, and job roles.
